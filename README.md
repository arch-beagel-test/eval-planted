# eval-planted

Planted pull requests for ArchBeagle's findings suite (architecture/0095, ArchBeagle/archbeagle#1513). Each open pull
request is one case: a positive that breaks one rule, or a near miss that looks like it and doesn't. The cases'
expected findings are in `review/src/arch_review/checks/evals/cases.yaml` in ArchBeagle/archbeagle.

Secrets here are published example values only (jwt.io's sample token); none grants access to anything.
